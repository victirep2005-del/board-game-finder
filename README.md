# Board Game Finder

Si quiero hacer una aplicación o una página web para un negocio que tengo de juegos de mesa, en el que quiero básicamente hacer un buscador en el sentido de que yo voy a catalogar los juegos. Tengo tres cuartos, en cada cuarto hay varios estantes. O sea, quiero que al buscar el nombre de un juego me digan qué estante y en qué cuarto está y eventualmente añadir más información.
